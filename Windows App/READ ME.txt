TOOL DRIVE OFFLINE 2.0 FOR WINDOWS

Open Tool.Drive.Offline.exe on Windows 10 or 11. The app uses .NET Framework
4.8 and the Microsoft Edge WebView2 Runtime. If the runtime is missing,
install the Evergreen Runtime from Microsoft and reopen the app:
https://developer.microsoft.com/microsoft-edge/webview2/

The EXE includes 1,299 shows, all theme artwork, and the catalog captured on
November 21, 2026. Browse, search and bookmark without an internet connection.
Choose an available recording and select Stream to play its published audio.

APPEARANCE
New installations start in Liquid Glass. Open Appearance to choose Liquid
Glass, Front Row, Night Shift, Graphite, or Laser Grid. In Liquid Glass you
can pick any of nine concert photos. Wallpaper > Shuffle changes the photo
on launch. Front Row remembers its own picture. Choose a Classic or 2006
logo, the running window's icon, zoom level, and a card or resizable column
layout. The EXE and its shortcuts use the multicolor TOOL icon.

FIND A SHOW
Press Ctrl+F to search by date, venue, location, taper, equipment or song.
Combine sound rating, years, source status and recording type. The rating
is the best recording quality among sources meeting your filters. Pick a
show opens a random result. The star saves a show for later. Open a show to
see source details, lineage, setlists and streaming or Library actions.

PLAYER AND LIBRARY
Use the player to select a track, seek, pause, or skip. Tracklist can open
from the left, right or bottom. Open Visualizer for Ember Bloom, Tidal Glass,
Prism Veil or Infinite Filigree. The visualizer responds to the audio and
supports full screen. EQ offers Bass Boost, Vocal, Bright, custom bass/mid/
treble, and the eight-filter Magik setting. Flat clears the effects.

Save to Library downloads a complete recording for offline playback. Open
download opens an isolated Google Drive window for published originals.
Select a supported download to import it. You can also import audio files
or a ZIP from a recording's source, or use Import audio in Library. The
Library keeps the original files. A bundled decoder handles supported
lossless and PCM formats when the browser needs a different playback format. Completed recordings appear together;
canceling a partial download leaves existing recordings available.

PLEX
Open Plex, choose Connect, and complete sign-in in your browser. Select a
server and a music library, then open a recording and search or play its Plex
match. Matching uses the concert date and recording version. Plex credentials
are protected using Windows data protection under your account. Disconnect
in Plex to remove the saved credential. Plex audio requires connectivity
to the selected server.

UPGRADES AND STORAGE
Your 1.x bookmarks, catalog cache, and saved column widths carry over. The
app stores them in %LOCALAPPDATA%\Tool Drive Offline along with the Library,
Plex settings, and the private web profile that remembers Appearance.

Updates has separate controls for catalog metadata and the Windows app.
A catalog refresh validates all four metadata snapshots before replacing
the working cache. The app updater verifies the repository, release version,
SHA-256 digest, size and executable identity. Choose Restart to update when
ready. Updating requires write access to the executable's folder.

BUILD FROM SOURCE
Run Windows App\build-app.ps1 with Python 3.9+ and .NET Framework installed.
The first source build verifies Microsoft's pinned WebView2 SDK from NuGet.
The standalone source ZIP includes the pinned SDK under Dependencies. You
can also pass -WebView2Package to use a previously downloaded SDK file. The Windows
source package includes the standalone catalog, shared desktop assets and
rebuildable Windows components. Run Windows App\test-app.ps1 after building.

The Windows release ZIP includes notices for Microsoft WebView2 and FFmpeg.
The corresponding decoder sources and build script are in the Windows
source ZIP under Windows App\Codecs.
