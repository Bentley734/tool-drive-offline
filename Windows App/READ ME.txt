TOOL DRIVE OFFLINE - WINDOWS APP

Double-click Tool Drive Offline.exe to open the app.
No installation, administrator rights, browser, or local server is needed.
The entire show catalog is embedded in the executable. You can move the EXE
to any folder, or pin it using Windows' normal taskbar/Start controls.

This app uses .NET Framework 4.8, which is already installed on this PC.
Another computer must also have .NET Framework 4.8 or later installed.

FIND A SHOW
Search for a date, venue, city, taper, or song. Filter by sound rating,
recording type, year, and source status. Open a show for its recording
versions, lineage notes, and setlist. Copy its date and search in Plexamp
for your own recording. The app does not connect to Plex or inspect your
music library.

All ratings measure recording SOUND QUALITY out of 10. The score shown for
a show is the highest rating among sources matching ALL your filters.
Unrated recordings are not zero-rated. Vote counts are unavailable.

The default status is OTD (on the project's drive). Confirmed means a
recording exists but the project has not acquired it; Unconfirmed means
believed to exist; Unknown means no known recording. These labels do not
describe what is in your Plex library.

OFFLINE DATA
1,299 shows from the Tool Drive Project's public metadata, downloaded
November 21, 2026. Setlists originate from setlist.fm and may be partial.
This is an independent personal offline browser. The bundled data remains
available until you request a successful catalog update. No audio was
downloaded or bundled, and there are no streaming or download links.

CHECK FOR CATALOG UPDATES
The app displays the saved catalog immediately, then automatically checks
for updates once each time you open it. You can keep browsing during the
check. Use Check for catalog updates to check again later. The app requests only four public metadata files from
Tool Drive Project. It reports new shows, recordings, ratings, and other
changed metadata, then stores a validated copy for later offline use.
Cancel update stops an active check. A failed or canceled check keeps the
working catalog. Your search, filters, and saved shows are preserved.

If you are offline, the saved catalog remains usable. Recent changes may
take time to reach the site's published metadata files. Last checked shows when
your check succeeded; it is not the edit date of every recording.
The catalog control updates data; app EXE updates are handled separately.

Updated metadata is cached separately at:
%LOCALAPPDATA%\Tool Drive Offline\catalog-update.json
If that cache cannot be loaded, the embedded catalog remains available.

APP UPDATES FROM GITHUB
The app checks for newer stable GitHub releases when it opens. If there is
one, it downloads the Windows EXE in the background and verifies the file's
SHA-256 digest, size, app identity, and version.

Click Restart to update when you are ready. The app closes, replaces its
EXE, and starts the new version. You do not need to download or replace the
file by hand. Check app updates can check again or cancel an active check.
If you are offline, the current app and catalog remain usable.

Saved shows, cached metadata, and column widths remain in your Windows
profile. The helper keeps or restores the old EXE if replacement or restart
fails. The EXE folder must be writable, and other copies using the same EXE
must be closed. No administrator access or login is requested.

Temporary app-update files are stored under:
%LOCALAPPDATA%\Tool Drive Offline\AppUpdates

Versions before 1.3.0 need this updater-enabled EXE installed once. Later
versions can update themselves using Restart to update.

SAVED SHOWS
Saved show IDs are stored in:
%LOCALAPPDATA%\Tool Drive Offline\saved-shows.json
They remain saved when you move or replace the EXE on the same Windows
account. This list is separate from the earlier HTML browser's saved list.
If the app cannot save the file, it reports that the list is session-only.

COLUMN WIDTHS AND LARGE LISTS
Drag column header edges to resize the columns. Widths are saved after a
short pause and when the app closes normally, and restored next time.
Settings are stored separately at:
%LOCALAPPDATA%\Tool Drive Offline\column-layout.json
All columns remain available through horizontal scrolling when needed.
Large lists use virtual rows and create display values as needed instead
of rebuilding every cell after a filter changes.

SOURCE AND REBUILD
The project folder contains the C# source, icon, manifest, and build-app.ps1.
Run build-app.ps1 in PowerShell to rebuild using the installed .NET Framework
compiler. It embeds the existing ../catalog.json; building needs no network.
